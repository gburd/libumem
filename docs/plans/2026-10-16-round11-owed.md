### Task 3 -- Two AAL gaps on riscv64/arm32 (getpcstack + lock-free rseq)
FULLY ACHIEVABLE on kiwi QEMU.
- getpcstack: getpcstack.c already has x86_64/aarch64/SPARC frame walks;
  riscv64 and arm32 fall to the generic depth-0 path. Add per-arch frame-

  Validate under QEMU: pal_aal_smoke getpcstack depth > 0.
- lock-free rseq: write aal/umem_rseq_riscv64.S and umem_rseq_arm32.S OR

  model rseq/cpu-migration, so a "passing" QEMU run would NOT prove the asm

  risks the exact false-green the project forbids. Decide: either write it +
  mark "unvalidated, needs real riscv/arm32 hardware" (honest but unproven),
  or keep the fallback + document why. Lean to the latter unless hardware
